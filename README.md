# ☕ Java Master: De Cero a Microservicios & Spring Boot

Repositorio integral con el código fuente, laboratorios y proyectos desarrollados a lo largo del programa integral de formación en el ecosistema **Java moderno**, abarcando desde fundamentos de arquitectura hasta arquitecturas empresariales distribuidas, desarrollo Full Stack y programación reactiva.

---

## 🧭 Módulos y Áreas de Dominio

### 1. Fundamentos & Core Java Avanzado
* **POO & Clean Code:** Programación Orientada a Objetos, principios SOLID, patrones de diseño y manejo robusto de excepciones.
* **Java Moderno:** Programación funcional con Expresiones Lambda y Stream API.
* **Concurrencia:** Hilos (*Threads*), sincronización y aplicaciones concurrentes.
* **Testing:** Pruebas unitarias y mockeo con **JUnit 5** y **Mockito**.

### 2. Interfaces Gráficas & Eventos en Tiempo Real
* **Desktop UI:** Desarrollo de aplicaciones de escritorio con **JavaFX** y **Swing**.
* **WebSockets:** Implementación de sistemas de chat y eventos en tiempo real con Spring Boot, JavaFX y Angular.

### 3. Desarrollo Empresarial (Jakarta EE / Java EE)
* **Jakarta EE 9:** Servlets, JSP, persistencia con JDBC/JPA, EJB 4 y arquitectura de microservicios Jakarta.
* **Inyección de Dependencias:** Gestión de contextos con Weld CDI.
* **Servicios Web:** Desarrollo de APIs RESTful (JAX-RS) y servicios SOAP (JAX-WS) desplegados en **JBoss WildFly**.
* **UI Empresarial & Seguridad:** JSF, PrimeFaces y esquemas de seguridad JAAS.

### 4. Ecosistema Spring Boot & Persistencia
* **Spring Framework & Boot:** Inyección de dependencias (IoC/DI), configuración y ciclo de vida de beans.
* **Spring MVC & Forms:** Validación de datos (Bean Validation), interceptores HTTP y manejo global de errores (`@ControllerAdvice`).
* **Persistencia:** Spring Data JPA, Hibernate, modelado relacional y paginación con bases de datos MySQL.
* **Seguridad:** Autenticación, autorización basada en roles y flujos personalizados con **Spring Security**.

### 5. Full Stack & Programación Reactiva
* **Full Stack Integration:** Arquitectura multicapa desacoplada con **Spring Boot + Angular + RESTful APIs**.
* **Spring WebFlux & Project Reactor:** Programación no bloqueante basada en Reactive Streams y operadores ReactiveX.
* **Ecosistema Distribuido:** Bases de Spring Cloud para la transición hacia microservicios.

---

## 🛠️ Stack Tecnológico

* **Lenguaje:** Java (JDK 21+)
* **Frameworks Core:** Spring Boot 3.x, Spring Data JPA, Spring Security, Spring WebFlux, Jakarta EE 9
* **Frontend & UI:** Angular, JavaFX, Swing, JSF / PrimeFaces, Bootstrap
* **Testing & Tools:** JUnit 5, Mockito, Apache Maven, IntelliJ IDEA, Spring Tools 4
* **Bases de Datos & Servidores:** MySQL, WildFly Server
